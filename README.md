# XunSound

XunSound 是一个本地运行的 AI 换声与歌曲制作工具。  
你可以用自己的声音训练一个专属声音模型，再把歌曲里的人声替换成这个声音；也可以用 AI 生成歌曲、生成背景图，并导出适合分享的 MP4 片段。

它基于开源 RVC 语音转换技术构建，并封装成更适合普通用户使用的网页界面和 Windows 便携版。

## 主要功能

### 训练自己的声音模型

上传一段清晰的人声素材，系统会自动整理音频、提取特征并训练声音模型。

第一次制作时，目标歌曲不是必填：

- 只上传声音素材：只训练声音模型
- 上传声音素材和目标歌曲：训练完成后自动换声

### 用已有声音换歌

选择已经训练好的声音，上传目标歌曲，即可生成：

- 换声后的完整歌曲
- 纯人声版本
- 可裁剪片段
- 可导出的 MP4 视频

### AI 生成歌曲

输入歌曲主题、风格或歌词方向，生成一首新的歌曲。  
生成后可以在线试听、下载，也可以直接拿去换声。

### AI 生成背景图

输入画面提示词，生成竖版背景图。  
生成的背景图可以下载，也可以直接用于 MP4 制作。

### 制作 MP4 片段

在结果页可以截取歌曲片段，上传或生成多张背景图。  
多张背景图会在视频里自动循环轮播，并叠加动态视觉效果。

### 导入已有 RVC 模型

如果你已经有 RVC 模型，可以把 `.pth` 和 `added_*.index` 放进便携包继续使用。

## 使用场景

- 用自己的声音制作翻唱、祝福歌、纪念歌
- 把 AI 生成歌曲换成指定声音
- 给歌曲片段制作带背景图的 MP4
- 用更简单的网页界面使用已有 RVC 模型
- 在本地电脑运行，不依赖在线换声平台

## 推荐配置

- 系统：Windows 10/11
- 显卡：推荐 NVIDIA 显卡
- 显存：8GB 可用，16GB 更稳
- 磁盘：建议预留 20GB 以上空间

没有显卡也可以使用 CPU 推理或训练，但速度会明显变慢。

## AI 功能说明

AI 生成歌曲和 AI 背景图需要配置 MiniMax API Key。  
未配置 API Key 时，不影响本地训练和换声功能。

## 导入已有模型

已有 RVC 模型通常需要两个文件：

```text
模型名.pth
added_*.index
```

放置结构：

```text
XunSound_Portable\app\assets\weights\模型名.pth
XunSound_Portable\app\logs\模型名\added_xxx_模型名_v2.index
```

例如：

```text
app\assets\weights\lishun.pth
app\logs\lishun\added_IVF778_Flat_nprobe_1_lishun_v2.index
```

重启服务后，系统会自动扫描并导入。  
如果使用手机号账号，或模型没有显示，请查看便携包里的 `导入已有模型教程.md`。

## 常见问题

### 训练完成后必须马上换歌吗？

不用。可以只训练声音模型，以后再选择歌曲进行换声。

### 没有 NVIDIA 显卡可以用吗？

可以，但会比较慢。系统会尽量自动检测显存和内存；如果 GPU 不可用，会尝试切换到 CPU。

### 可以上传多张背景图吗？

可以。多张背景图会在 MP4 中循环轮播。

### AI 生成的背景图会永久保存吗？

不会。背景图默认只保存在当前页面中，刷新页面后不会保留。需要的话请自行下载。

### 导入模型后页面没有显示怎么办？

请检查：

- `.pth` 是否放在 `app\assets\weights`
- `added_*.index` 是否放在 `app\logs\模型名`
- 当前登录账号是否和模型注册账号一致
- 是否已经重启服务或刷新页面
